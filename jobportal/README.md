# MatchWorkers Job Portal

This is a custom Next.js application designed and developed for **MatchWorkers**.

The application may be used and modified by MatchWorkers for its own internal business operations.

## Getting Started

Install the project dependencies:

```bash
npm install
```

Create and configure the required environment variables in the `.env` or `.env.local` file.

Run the development server:

```bash
npm run dev
```

Open the following address in your browser:

```text
http://localhost:3000
```

## Production Build

Create a production build:

```bash
npm run build
```

Start the production application:

```bash
npm run start
```
